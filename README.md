# 🎮 Tic Tac Toe - ReactJS

A simple and interactive **Tic Tac Toe** game built using **React 19** and powered by **Vite** for fast development.

---

## 🚀 Features

- ⚛️ Built with **React 19**
- ⚡ Super-fast with **Vite**
- 🎯 Classic 3x3 Tic Tac Toe logic
- 🔁 Easy to restart and play again
- 🧠 Turn-based player switching


## 🧑‍💻 Installation & Running Locally

### 🔧 Steps
```bash
git clone [https://github.com/your-username/tic-tac-toe-react.git]
cd tic-tac-toe-react
npm install
npm run dev
